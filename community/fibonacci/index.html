Fibonacci in Littleman

A complete one-man example using two data registers and BP as a countdown.

Unofficial community tutorial. This was added after ICFPC 2026 and is not part of the captured organizer problem set.

The complete machine

+-+  +------------+
|I|>>|@rb0M1Wv    |
+-+  |            |  +-+
     |       > dsH|>>|O|
     |         +  |  +-+
     |         W  |
     |         m  |
     |       ^ <  |
     +------------+

There are three rooms, but only one contains a man. The other two are the required input and output rooms. No relay is needed because this algorithm does not store a data stream in a feedback pipe.

Initialization

The man begins at @, facing right:

@ r b 0 M 1 W v
Instruction Effect
r Receive n into A.
b Copy n into BP.
0 M Set A = 0, then copy it to B.
1 W Set A = 1, then swap: A = 0 and B = 1.
v Turn toward the loop controller.

The loop begins with:

A = F₀ = 0
B = F₁ = 1
BP = n

The loop controller

The man reaches d while facing right. If BP is positive, d turns him clockwise and down into the loop. If BP is zero, he continues straight to s, sends A to the output, and halts on H. 

              d → s → H
              ↓
              +
              W
              m
            ↑ ←

This is how BP can control a loop despite having no general read instruction.

One Fibonacci step

At the start of iteration k, maintain the invariant:

A = Fₖ
B = Fₖ₊₁

+ and W transform the pair:

+ : A = Fₖ + Fₖ₊₁ = Fₖ₊₂,  B = Fₖ₊₁
W : A = Fₖ₊₁,               B = Fₖ₊₂

Then m decrements BP and the arrows route the man back to d. After exactly n iterations, A contains Fₙ.

On the next visit to d, BP is zero, so the machine emits A = 5.

About relay rooms

A pipe cannot return to the room it started from. When a solution needs a persistent FIFO ring, it therefore adds a tiny second room. Its man repeatedly receives with r and sends with s, connecting two legal one-way pipes into a logical feedback loop. Fibonacci needs only the current pair, so A and B are sufficient and the relay is absent.
